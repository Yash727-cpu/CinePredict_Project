# CinePredict — Movie Success Prediction

## 1. Install packages
Open a terminal in this folder and run:

```bash
python -m pip install -r requirements.txt
```

## 2. Add your model
Copy the model generated by your training script to:

`model/movie_success_model.pkl`

If you have not trained the model yet, place your cleaned dataset at `dataset/cleaned_movies.csv` and run `python train_model.py` from this project folder. Create the `dataset` folder and provide your actual cleaned CSV; the dataset is not included. Note: your existing training script runs a very large GridSearchCV and may take a long time. Make sure the `model` directory exists before running it (already included here).

## 3. Start the website

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Important
- Without the trained `.pkl` file, the UI displays a clear error rather than a fabricated prediction.
- Load only `.pkl` model files you created or trust.
- Input budget units must match your training dataset. The form currently labels budget in dollars; change it if your dataset uses another unit.
- Audience ratings, vote counts and popularity may be unavailable before movie release. This is not a pure pre-release predictor.
- The 79.88% accuracy shown on the page comes from your earlier presentation; this application does not independently verify it.
